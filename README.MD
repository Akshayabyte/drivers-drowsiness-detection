# 🚗 Driver's Drowsiness Detection System

## 📌 Project Overview

Driver's Drowsiness Detection System is a safety-focused project designed to detect signs of driver fatigue in real time and provide an early warning to the driver.

The system uses a camera to monitor the driver's face and eyes. When prolonged eye closure or other signs of drowsiness are detected, an alert is activated.

## 🎯 Problem Statement

Driver fatigue can reduce attention and reaction time and may contribute to road accidents. A system that can detect possible drowsiness and warn the driver can provide an additional layer of safety.

## 💡 Proposed Solution

A camera continuously monitors the driver's face. A computer vision algorithm analyzes the driver's eyes and facial features to identify possible drowsiness.

### Working

Camera → Face Detection → Eye Analysis → Drowsiness Detection → Alert
